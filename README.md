# Índice

Este repositorio contiene soluciones de los ejercicios del curso
[Introduction to real analysis](https://alexkontorovich.github.io/2025F311H/) de [Alex Kontorovich](https://math.rutgers.edu/~alexk) en la [Universidad
Rutgers](https://es.wikipedia.org/wiki/Universidad_Rutgers).

De cada uno de los ejercicios se muestran distintas soluciones que
varían en su grado de automatización o en su carácter declarativo.
